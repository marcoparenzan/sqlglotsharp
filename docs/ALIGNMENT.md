## 6. Differences from the official project

| Area | Difference |
|---|---|
| Extension | `Dialect.CreateParser/CreateGenerator/CreateTokenizer` are virtual (Python uses class attributes); `Dialect.register/unregister` |
| API | `exp.column(...)`, `Expr.sql(dialect)`, `SqlGlot.transpile/parse_one` mirror the Python names; PascalCase aliases exist only on `SqlGlot` |
| Optimizer | Subset: `TypeAnnotator` (expression level) and `Simplifier` (without date/interval and constant propagation) |
| Registry | Only base, postgres, tsql, fabric, timescale are built in (extensions such as `layer3` register themselves); other official names raise `NotPortedException` |
| Errors | Unported grammar or transforms raise `NotPortedException`; there is never a silent fallback |
| Hash anchors | Files written after the generator era use `// py: path::Name` without a hash, so section 4 under-reports them |

## 8. Realignment procedure (new official release)

The full procedure, the triage rules and the sync log are in [UPSTREAM-SYNC.md](UPSTREAM-SYNC.md). In short:

1. In `python/` (read-only, git-ignored): `git fetch --tags` and `git checkout <new-tag>`; update `UPSTREAM.json` (tag, commit).
2. Re-record the corpus with the oracle (`src/tools/extract_corpus.py`, environment: `src/tools/run-oracle.ps1`), into a fresh directory outside the repository.
3. Run the Scoreboard on the new corpus: every difference is a `Fail` or `NotPorted` and `notported.json` is the work list.
4. Regenerate the generated files (`src/tools/gen_csharp.py`, `gen_typing_metadata.py`) and rebuild; stale anchors show up in `port_status.py`.
5. Port the changed members (section 7 lists them), keeping the `// py:` anchors; add oracle-based tests for each behaviour change.
6. Re-run the unit tests and the full Scoreboard until `Fail = 0` and `NotPorted = 0`, a full run without an output argument writes to `docs/status/`, rerun `gen_alignment.py`.
7. The host `layer3` corpus (`corpus.json`, recorded with sqlglot 30.23.0) is compared against the new release: regenerate `src/SqlGlotSharp.Extensions.Layer3.Tests/Layer3/expected.json` with `gen_layer3_expected.py` and review any difference.
